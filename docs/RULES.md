# Dami 加密日報判讀規則

近 15 天取連續 90 根已收盤 4H，依時間均分五段、每段 18 根。五個高點和五個低點必須全部嚴格遞增或遞減，並符合均線排列。EMA 從抓取範圍第一個收盤價開始遞推，布林採母體標準差，RSI 採 Wilder 平滑。維持保證金率預設 0.5%，僅供試算。

3. 資料來源（沿用現行可用的來源）
3.1 加密行情（公開 API，不需金鑰）
Binance 現貨 `https://data-api.binance.vision`
4H K 線：`/api/v3/klines?symbol=BTCUSDT&interval=4h&limit=151`。只用已收盤 K 線（最後一根若 closeTime > 現在就丟掉）。
24h 行情：`/api/v3/ticker/24hr?symbols=["BTCUSDT","ETHUSDT"]`（價格、24h%、高、低、成交額）。
注意：雲端連 `api.binance.com` 會被地區封鎖（451），用 `data-api.binance.vision`，不要換網址繞過。
alternative.me `https://api.alternative.me/fng/?limit=2`：恐懼貪婪（今值、前值、中文標籤、UTC 日期）。
OKX 公開 API
資金費率：`/api/v5/public/funding-rate?instId=BTC-USDT-SWAP`（ETH 同理），×100 變成每 8 小時百分比。
OI 歷史：`/api/v5/rubik/stat/contracts/open-interest-volume?ccy={BTC|ETH|SOL}&period=1H`（新到舊；第 0 筆 vs 第 24 筆算 24h 變化）。
多空帳戶比：`/api/v5/rubik/stat/contracts/long-short-account-ratio?ccy=BTC&period=1H`，多方 % = r/(1+r)×100。
強平明細：`/api/v5/public/liquidation-orders?instType=SWAP&uly={coin}-USDT&state=filled&limit=100`，用 `after` 翻頁，累加近 24h；`side=sell` 是多單被強平、`side=buy` 是空單被強平；金額 = sz × ctVal × bkPx（ctVal 從 `/api/v5/public/instruments` 取）。設最多 80 頁上限，超過標 `capped:true`。OKX 只保留約 1 天。
主動買賣量：`/api/v5/rubik/stat/taker-volume?ccy={coin}&instType=CONTRACTS&period=1H`，取近 24 筆合計。
Deribit `/api/v2/public/get_book_summary_by_currency?currency={BTC|ETH}&kind=future`：open_interest 加總（美元）。
Hyperliquid `POST https://api.hyperliquid.xyz/info` `{"type":"metaAndAssetCtxs"}`：OI × markPx。
每個欄位都要附 `src` 與限制說明，例如：「OKX＋Deribit＋Hyperliquid 合計，不含 Binance、Bybit、CME，不代表全市場」、「僅 OKX USDT 永續強平單，不代表全市場」。
全市場 OI：只有 CoinGlass 或 CoinDesk／The Block 報導引用的跨交易所數字才算全市場。程式抓不到時，報告要寫「全市場 OI 未取得」。
3.2 美債殖利率（官方）
美國財政部 CSV：
`https://home.treasury.gov/resource-center/data-chart-center/interest-rates/daily-treasury-rates.csv/{年}/all?type=daily_treasury_yield_curve&field_tdr_date_value={年}&page&_format=csv`
日期格式 MM/DD/YYYY；欄位 `1 Mo`、`3 Mo`、`6 Mo`、`1 Yr`、`2 Yr`、`3 Yr`、`5 Yr`、`7 Yr`、`10 Yr`、`20 Yr`、`30 Yr`。
今年不足 90 個交易日就合併前一年。報告的 2Y、10Y 一律以此為準，並標明美東收盤日期。
計算：2Y、10Y、10Y−2Y 利差（bp）、一日變化、約 21 個交易日前的變化；曲線型態判定：
熊陡：長端升幅 > 短端（利差擴大且殖利率上升）
熊平：短端升幅 > 長端，或短升長降（利差收窄）
牛陡：短端降幅 > 長端（利差擴大且殖利率下降）
牛平：長端降幅 > 短端（利差收窄且殖利率下降）
3.3 新聞（由 agent 讀取與查證）
指定五站：CoinDesk、The Block、動區 BlockTempo、BlockBeats、CryptoPanic。
重大事件要用 Reuters、CNBC、Bloomberg 轉載、官方公告等交叉查證；只有社群或單一來源的標「未確認」。
已知問題：CoinDesk 首頁快取曾停在 10/27、The Block 與 CryptoPanic 曾停在 11/17。程式要檢查頁面上最新文章的日期，超過 24 小時就標「來源過期，未採用」，不可把舊新聞當今天的。
被拒絕讀取的網站不要用其他方式繞過，寫「無法讀取」。
3.4 美股
雲端連 Yahoo、Stooq 的 API 會被擋，不要用程式硬抓或換網址繞過。改用可以合法取得的來源（例如 TradingView MCP、新聞稿、收盤整理文章），每個數字標來源與時間、是否延遲。
均線只用可查證的報價頁或自己用可信日 K 計算；兩者都沒有就寫「未取得」，不要推估。
同一欄位兩個來源互相矛盾或明顯重複（例如 11/18 PANW 盤後欄位與常規盤數字重複）就不採用，並寫明原因。

4. 追蹤範圍
加密：BTC 為主、ETH 次之；SOL 只出現在合約數據。當天有主線幣種才加。
美股預設追蹤：QQQ、SPCX、NVDA、TSLA、TSM、AMD、MSFT、GOOG、GOOGL、GLW。QQQ 是整體風險開關。
指數：S&P 500、Nasdaq 100、道瓊、費城半導體 SOX、Russell 2000、VIX；ES／NQ 期貨（台北時間報價，標延遲）。
總經：DXY、WTI（標合約月份）、黃金、Fed 升息機率（CME FedWatch 或 Kalshi，標來源）。
類股：11 個 SPDR 類股 ETF（XLK、XLF、XLE、XLV、XLY、XLP、XLI、XLB、XLU、XLRE、XLC）當日最強與最弱各 3 個。
加密相關股：COIN、MSTR、IBIT（看和 BTC 是否同步、放大倍數）。
ETF 流量：美國現貨 BTC／ETH ETF 前一交易日淨流量（優先 Farside；或多家報導一致的數字），單位百萬美元，流出為負。

5. 判讀規則（全部寫進 `docs/RULES.md`，程式能檢查的就寫成檢查）
5.1 趨勢方向（程式判定，與「今日動作」分開）
只用已收盤 4H K 線與自行計算的 EMA20、EMA50：
收盤 < EMA20 < EMA50，且近 15 天的高點、低點逐步下移 → 空頭趨勢
收盤 > EMA20 > EMA50，且高點、低點逐步上移 → 多頭趨勢
其他 → 盤整
趨勢方向不因 OI、清算、ETF 流量或資金費率而改寫。報告要寫出依據的收盤價、EMA20、EMA50，以及近 15 天的高／低點序列。
採本頁開頭五段規則。
5.2 衍生品判讀
OI 以跨交易所加總為準，標明時間範圍（24h 或日數據）。
只有單一或部分交易所數據時，標「僅 X 交易所，不代表全市場」，且不得據此判斷「有新多單進場」或「純空單回補」。
OI 與清算只用來決定**「今天追不追、部位多大」**，不否決趨勢方向：
上漲伴隨大量空單清算、但全市場 OI 未確認增加 → 視為空單回補、新買盤未確認 → 不追多，等回測支撐不破再進，部位減半。
下跌伴隨大量多單清算、但全市場 OI 未確認增加 → 不追空，等反彈到壓力不過再進，部位減半。
全市場 OI 確認同向增加時，才能用突破／跌破追單與完整部位。
鏈上轉帳不等於買賣；交易所流入不等於一定會賣。
5.3 前次判讀修正
新數據和上一份報告的判讀矛盾時（例如 OI、清算、ETF 流量方向相反），在報告最前面、一句話結論之前加「⚠ 前次判讀修正」：原判讀、新數據（來源與時間）、修正後結論，並同步調整或撤下受影響的建議操作。不可只寫在內文。此時 JSON 的 `headline` 以「【修正】」開頭。沒有矛盾時寫一行「不需前次判讀修正」。
5.4 技術指標
主要依據：價格結構、成交量、EMA20／50、布林通道（20, 2）、OI、資金費率、多空比。
RSI14 只當輔助，不能當主要理由。
所有自行計算的數值標「自行計算」，並寫明資料範圍（例如「11/4 04:00–11/19 00:00，90 根」）。
5.5 資料標示
每個數字都要有：來源、時間（台北或註明美東）、是否延遲。區分「已確認」與「未確認（僅社群來源）」。找不到就寫找不到。

6. 建議操作規則（早晚報都必寫）
先給兩行，分開寫：
趨勢方向：多頭趨勢／空頭趨勢／盤整（附收盤、EMA20、EMA50）。
今日動作（晚報寫「今晚動作」）：偏多候選／偏空候選／等回測再多／等反彈再空／觀望／減碼風險，附原因（含 QQQ 風險開關）。
趨勢是多頭或空頭時，至少給一個順勢候選（空頭＝反彈到壓力不過的空單；多頭＝回測支撐不破的多單），不能只寫觀望。只有以下情況可以寫觀望，並寫明是哪一項：趨勢為盤整；順勢候選風報比 < 1.5；符合不交易條件。
BTC 三情境表（必要時加 ETH）：多頭、空頭、盤整（不交易）。欄位：觸發條件、進場、停損（含依據）、目標 1／目標 2、風報比、損益（停損／T1／T2）、失效條件。
順勢列以「回測／反彈進場」為主；另用一行文字寫「突破／跌破追單」版本（需全市場 OI 同向增加才成立）。
逆勢列標「逆勢、部位減半」。
部位試算（程式計算，不要手算）：
預設：100 USDT 保證金 × 20 倍 = 名目 2,000 USDT。
部位減半：50 USDT × 20 = 名目 1,000 USDT，並標明。
損益 ≈ 名目 × (出場價 − 進場價) / 進場價（空單取反）。
粗估強平價：多單 ≈ 進場 × (1 − 1/槓桿 + 維持保證金率)，空單反之；停損必須在強平價之前，否則該情境作廢。
註明：未計手續費、資金費、滑價及交易所實際強平規則；20 倍約 5% 反向波動就可能強平。
美股：
早報：「美股今晚觀察」挑 1–3 檔（含 QQQ）：觀察重點、成立條件、失效價位（含依據）、短線 2–5 天傾向。
晚報：挑 1–3 檔（含 QQQ），分短線（2–5 天）與長線（幾週到幾個月）：動作（觀望／分批布局候選／減碼／等待回測）、觸發條件、參考進場、停損或失效（含依據）、目標、風報比。
資料不足的標的直接寫「資料不足，不給建議」。
不交易條件：例如價格在盤整區內；觸發 K 量低於近 90 根均量；資金費率 > +0.03% 不追多、< −0.03% 不追空；重要數據公布前後 1 小時；美股開盤首小時；ETF 數字公布前後 1 小時；FOMC 相關事件前後 2 小時。
固定兩行：
「順勢候選是依均線與價格結構的規則式訊號，未經回測驗證，訊號變多代表假訊號也會變多。」
「沒有使用者最新持倉資料，以上不假設已有倉位、不沿用舊倉推算。」
結尾固定一行：「以上為候選訊號，需自行判斷並手動下單；不是投資建議，不保證走勢或報酬。」
週末／美股休市：早報改寫「上週美股回顧＋本週事件與財報預告」，晚報改寫「下週開盤前的準備方案」，不要假裝有新收盤或盤中訊號，也不要重複貼上次的表格。

7. 早報格式（約 1,000–1,600 字）
開頭說明區塊：產出時間、各資料的來源與時間、是否延遲；接著「前次判讀修正」或「不需前次判讀修正」。
一句話結論：BTC 趨勢方向 → 今日動作 → QQQ 風險開關 → 昨晚美股一句話。
價格快照：BTC、ETH 價格、24h%、24h 低／高；恐懼貪婪。
主線事件（1–3 件）：分「已確認」事實與「推論」。
美股收盤回顧：
指數表（S&P 500、Nasdaq 100、道瓊、SOX、Russell 2000、VIX、ES、NQ）；DXY、WTI、黃金
類股最強／最弱各 3 個＋資金輪動一句話
追蹤標的表：標的｜收盤｜漲跌%｜盤後｜20／50 日均線位置｜支撐／壓力｜備註
加密相關股 COIN、MSTR、IBIT 與 BTC 是否同步
財報：昨晚結果（vs 預期、盤後反應）＋今晚預告（台北時間）
QQQ 風險開關（開／關＋依據：均線位置、VIX、高低點結構）
TSM ADR 對台積電今天開盤的意義（一句）
衍生品：OI（全市場或標明範圍）、清算、資金費率、多空比、期權偏斜／到期。
資金流：ETF、交易所流向、穩定幣。
總經背景：美債 2Y、10Y、利差，一日與一個月變化，曲線型態，對 BTC 與美股的意義；美元、油價、VIX、升息機率。
因果鏈：現在發生什麼 → 共同原因 → 傳導管道（利率、美元、流動性、風險偏好）→ 先反應／後反應資產（美股、BTC、ETH、台股 ADR）→ 如何驗證。
K 線走勢解讀：近 15 天 BTC 4H 分 4–6 段，每段寫時間範圍、價格區間、均量、EMA／布林位置、原因（只用已查證事件，對不上寫「原因不明」）；特別說明昨晚美股時段 BTC 怎麼動；最後說明「現在的形狀」代表什麼。
前次驗證點與建議操作回顧：表格，狀態用 成立／不成立／觸發／未觸發／失效／待定／延後。
接下來如何驗證（BTC 與 QQQ 關鍵價位、今晚數據）。
判斷失效條件。
接下來建議操作（第 6 節規則）。
其他值得注意（短句條列，未確認的標明）。
來源（Markdown 連結）。
8. 晚報格式（約 900–1,400 字）
一句話結論（趨勢方向 → 今晚動作 → QQQ 開關與跨市場判斷）
總經與新聞（今晚／本週數據、Fed、美債、美元、油價；附台北時間）
跨市場因果鏈
美股資金與輪動
追蹤標的表：標的｜前收｜漲跌%｜盤前｜趨勢（EMA20／50 位置、量能）｜支撐／壓力｜備註
加密盤中更新：價格與自早報以來的變化、OI／清算／資金費率／多空比、ETF 前一交易日、早報驗證點回顧表
K 線走勢解讀（特別說明今天白天的走勢和美股、總經的關係）
重要觀察價位（BTC、QQQ、NVDA 等，含成立與失效條件）
接下來建議操作（第 6 節規則）
風險與今晚事件（台北時間）
來源
兩份都用白話寫，讓沒有交易背景的人看得懂；不要只貼利多／利空標籤。

## 休市日核對

草稿採用紐交所公告的 2026 至 2028 年休市日期。台北週末、當晚美股休市、或早報遇到前一晚休市時，自動切換回顧或準備方案。臨時停市與提早收盤由當班編輯核對，超出公告年份會列為待核對。[NYSE 交易日曆](https://www.nyse.com/trade/hours-calendars)
